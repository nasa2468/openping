# Security Policy

## Supported versions

Security fixes are provided for the latest released version of OpenPing.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If the repository has GitHub private vulnerability reporting enabled, use the **Report a vulnerability** option in the Security tab. Otherwise, contact the project maintainer privately through the contact information listed on the maintainer's GitHub profile.

Please include:

- a clear description of the vulnerability;
- affected versions or commits;
- reproduction steps or a proof of concept, when safe to provide;
- the potential impact.

Please allow reasonable time for investigation and remediation before publicly disclosing the issue.
